スマホを縦に持っている間だけ、ゲームの上に「画面を横向きにしてください」と重ねて出す部品です。出すか隠すかは、この部品ではなく CSS（`src/styles/rotate.css`、解説キット外）が決めます。

## このファイルが担うもの

- 案内の中身を作る。スマホの絵文字 📱 と、「画面を横向きにしてください」の 1 行です（L5-8）。
- 出し分けはしない。この部品はいつでも同じ中身を返し、ページに置かれたままです。縦に持っているかどうかで見せるか隠すかは、CSS が決めます（下の『読みどころ』）。

| 見た目を決められる | `src/styles/rotate.css`（解説キット外） | 縦に持っている間だけ、画面いっぱいに広げて出す |

## このファイルで初めて出てくる文法

ありません。`export function`（文法の索引の『import と export』）、JSX（文法の索引の『JSX』）、`className` だけで書かれています。

## 読みどころ

- **出し分けを CSS に任せている。** `src/styles/rotate.css` では、`.rotate-hint` をふだんは `display: none`（描かない）にしておき、`@media (hover: none) and (pointer: coarse) and (orientation: portrait)` に合う間だけ、画面いっぱい（`position: fixed; inset: 0`）に広げ、ほかの何よりも手前（`z-index: 100`）に出します。この条件は、`src/ui/landscape.ts` の L7 `PORTRAIT_TOUCH_QUERY` と同じです。端末を回すと、ブラウザが条件を判定し直して見た目を切り替えるので、React が描き直す必要がありません。
- **プレイ中に縦にすると、後ろのゲームは止まる。** 案内はゲームを隠すだけで、止めはしません。止めるのはプレイ画面の側で、同じ条件を `matchMedia` で見張り、縦になったら一時停止します（`src/ui/Play.tsx` の L165-169）。

## 落とし穴

- **パソコンでは、ウィンドウを縦長にしても出ません。** 条件の前半「マウスが無く、指で触る端末」（`src/ui/landscape.ts` の L4）に合わないからです。パソコンでこの案内を確かめるには、ブラウザの開発者ツールでスマホのふりをさせ、縦長の画面にします。
