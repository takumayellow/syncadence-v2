左に曲の一覧、右に選んだ曲の詳細（難易度ごとのレベル・ノーツ数・ランク、自己ベスト、PLAY ボタン）を並べ、矢印キーと Enter でも操作できる選曲画面の部品です。

## このファイルが担うもの

- 曲の一覧を、ジャケットの代わりの色付きの四角・曲名・作曲者と長さ・ランク・レベルの 1 行ずつで並べる（L92-119）。
- 選んだ曲の詳細と、4 つの難易度から 1 つを選ぶボタン、PLAY ボタン（L122-159）。
- キーボードでの操作（L43-63）。↑↓ で曲、←→ で難易度、Enter で始める。
- 選んだ曲が一覧の見える範囲に入るよう、一覧をスクロールする（L65-67）。
- 設定の引き出し（`SettingsDrawer`）の開け閉め（L38、L82、L173）。

この部品は**どの曲・どの難易度を選んでいるかを自分では覚えていません**。選んだ曲は `selectedId`、難易度は `difficulty` として `App` から受け取り、変えたいときは `onSelect`・`onDifficulty` で `App` に頼みます。自分で覚えているのは、引き出しが開いているかどうか（`drawerOpen`）だけです。
